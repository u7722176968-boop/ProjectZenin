# ProjectZenin
kleines Uno Spiel für den Informatik-Unterricht 4er Gruppe

Spielreihenfolge mit Befehlen:
1. Karten erzeugen mit ErzeugeKarten()
2. Karten mischen durch mischen() anfänglich mit dem Attribut 0
3. Karten auf Hände verteilen mit der verteilen methode
4. Karte aufdecken mit aufdecken(), hierbei wird die erste Karte aus verdeckt genommen und zu der letzten Karte von abgelegt
5. Spiel ansich startet


Info: getAnzahl(), 0 -> verdeckter Stappel, andere Zahl -> abgelegter Stappel
